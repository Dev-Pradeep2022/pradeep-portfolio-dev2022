# Pradeep Kumar Bal — Software Engineer Portfolio

React + Vite portfolio with responsive design, Framer Motion animations, project cards, skills, experience timeline, contact section and resume download button.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Personalize before deployment
1. Add your final resume as `public/resume.pdf`.
2. Replace `your.email@example.com` in `src/main.jsx`.
3. Add your LinkedIn/GitHub URLs if desired.
4. Update the experience dates to match your official employment history.
